KODA

Um agente de código seguro para o terminal, escrito em TypeScript. CLI e SDK.

$ koda _

Introdução

KODA lê seu projeto, edita arquivos e roda comandos, sempre pedindo aprovação para ações sensíveis. Funciona com vários provedores de LLM e é compatível com a estrutura de agentes, skills e comandos do OpenCode.

PROVEDORMODELO PADRÃO
openaigpt-4o-mini
anthropicclaude-3-5-sonnet-latest
geminigemini-2.5-flash
ollamallama3.2 (local)

Instalação

Requer Node >= 20.

npm install
npm run build
npm start       # ou: npm run koda (build + start)

O binário koda é exposto via bin/koda.js.

Configuração

Provedor e modelo são definidos por variáveis de ambiente.

# escolha o provedor (padrão: openai)
export KODA_PROVIDER=anthropic
export ANTHROPIC_API_KEY=sk-...
export ANTHROPIC_MODEL=claude-3-5-sonnet-latest
PROVEDORCHAVEMODELO
openaiOPENAI_API_KEYOPENAI_MODEL

Comandos customizados

Crie um arquivo Markdown em .koda/commands/. O nome do arquivo vira o comando.

# .koda/commands/review.md
---
description: Revisa um arquivo
agent: plan
model: openai/gpt-4o-mini
subagent: false
---
Revise o arquivo $1 com foco em $2.
Argumentos completos: $ARGUMENTS

Uso: /review src/index.ts segurança

Precedência (maior para menor): .koda/ → koda.json → .opencode/ → opencode.json → configuração global. Duplicatas no mesmo nível geram erro.

Agentes customizados

Definidos em Markdown (corpo = prompt) ou JSON, nos mesmos diretórios dos comandos.

---
description: Revisor de segurança
mode: subagent
model: anthropic/claude-3-5-sonnet-latest
temperature: 0.1
steps: 15
permission:
  edit: deny
  bash: ask
---
Você revisa código procurando vulnerabilidades.

Skills

Cada skill é uma pasta com um SKILL.md.

.koda/skills/<nome>/SKILL.md

Também são lidas as pastas .opencode, .claude e .agents. Liste com /skills.

Permissões

Cada ação resolve para allow, ask ou deny. Com padrões glob, a última regra que casar vence.

permission:
  read: allow
  edit: ask
  bash:
    "*": ask
    "git status": allow
    "rm *": deny

Chaves: read, edit, list, glob, grep, bash, task, skill.

Usar como lib

O pacote exporta o SDK em dist/src/index.js.

import * as koda from "koda";
Nota: o pacote é private e ainda não foi publicado no npm.
